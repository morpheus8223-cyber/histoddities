## The proven system (apply to every future title and description, not just this batch)

### Title formula — five proven mechanics, ranked by evidence strength

1. **Question-hook:** *"Why did/didn't/was/wasn't [specific actor] [counterintuitive outcome]?"* — the single strongest, most consistent long-form performer found in any channel sampled (History Matters: 27 of 30 videos land 400K–2.1M on this formula alone). The actor can be a person, a nation, or an institution.
2. **Myth-correction / contradiction:** state the assumption, then contradict it (*"X was never really about Y"*, *"Native Americans DID use armor"*). HistoryDose's single highest-performing video uses exactly this frame; it also drives comment-section arguments, which feeds distribution.
3. **Hyper-specific-detail declarative:** a real, concrete number or fact *as the headline itself* — "$100,000," "80,000 people," "seven months." Proven across HistoryDose's battle-stat titles, Bailey Sarian's shock-details, and already the convention several of this channel's own existing thumbnails use (Dracula: "HE KILLED 80000 PEOPLE").
4. **"How X happened/worked" explainer:** proven via Simple History and HistoryDose process-explainer titles.
5. **Absurd-cause declarative:** for "silly war" stories specifically — already proven on this channel's own back catalog (Emu War, Stray Dog War both already exist and perform).

**Non-negotiable rules for every title, no exceptions:**
- Never the channel name inside the title text
- Never a typo (check twice — the old catalog had the channel's own name misspelled twice)
- Never ALL-CAPS spam, emoji, double pipes, or exclamation-spam
- Exactly one clear curiosity mechanic per title — never a purely descriptive/museum-caption title ("X doing Y, year"), which is the single most proven-fatal pattern found (History Defined: 4–76 views per video using exactly this style)
- Front-load the hook within roughly the first 60 characters — full question-form titles can run to ~70 and still work (History Matters' proven pattern), but don't bury the point past that

### Description formula — evidenced from real top-performer descriptions, not assumption

Pulled directly from History Matters, HistoryDose, Simple History, and Bailey Sarian's actual live descriptions, cross-checked against current YouTube SEO guidance:

1. **Opening 1–2 sentences: a concrete specific fact**, not a generic AI-sounding opener ("Explore the enigmatic...", "Dive into this chapter..."). Aim to land the core claim inside the first ~150 characters — that's the window shown in search results before truncation.
2. **Optional second short paragraph** — more context/teaser, still concrete, no filler.
3. **A plain subscribe/CTA line.**
4. **Credits section, only when real** — art/script/music credits if applicable, affiliate links only once they exist and are verified. Never fabricated.
5. **2–4 relevant hashtags at the very bottom, never leading, never stuffed.** The first three hashtags used anywhere in the description become clickable chips displayed above the title — pick the best three for that specific slot.

Descriptions are a **secondary** ranking signal — engagement and retention outweigh them — but they matter enough to fix, and fixing them is mandatory wherever the title changes: the old descriptions quote the old typo'd titles verbatim, so leaving them as-is after a title fix creates a visibly broken mismatch.
